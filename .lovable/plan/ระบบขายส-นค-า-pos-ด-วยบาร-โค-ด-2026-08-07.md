# ระบบขายสินค้า (POS) ด้วยบาร์โค้ด

เพิ่มแท็บใหม่ **"🛒 สินค้า"** ในหน้าหลัก ใช้ได้ทั้งแอดมินและพนักงาน แบ่งเป็น 2 ส่วน: ขายหน้าร้าน (สแกน) และคลังสินค้า/สต็อก

## 1. คลังสินค้า (เพิ่ม/แก้สินค้า)
- ฟอร์มเพิ่มสินค้า: บาร์โค้ด (สแกนจากตัวสินค้าได้เลย), ชื่อสินค้า, ราคาขาย, จำนวนสต็อก
- ตารางรายการสินค้า: ค้นหาด้วยชื่อ/บาร์โค้ด, แก้ราคา/ชื่อ, เติมสต็อก (+N), ปิดการขาย (ไม่ลบประวัติ)
- เตือนสีเหลืองเมื่อสต็อกเหลือน้อย (≤ 5) และสีแดงเมื่อหมด

## 2. ขายหน้าร้าน (สแกนขาย)
- ช่องสแกน/พิมพ์บาร์โค้ด โฟกัสอัตโนมัติ กด Enter แล้วเพิ่มสินค้าเข้าตะกร้าทันที (รองรับเครื่องสแกน USB)
- ปุ่ม "📷 เปิดกล้องสแกน" สำหรับสแกนด้วยกล้องมือถือ/แท็บเล็ต
- ถ้าไม่พบบาร์โค้ด → แจ้งเตือนพร้อมปุ่ม "เพิ่มสินค้านี้" (เปิดฟอร์มพร้อมเลขบาร์โค้ดที่สแกน)
- ตะกร้าแสดงชื่อ ราคา จำนวน (เพิ่ม/ลด/ลบ) และยอดรวมตัวใหญ่
- ปุ่มยืนยันการขาย 2 ทาง:
  1. **ลงบิลเครื่อง** — เลือกเครื่องที่กำลังเล่น (PS5 โซฟา/รถแข่ง หรือ PC) จากรายการเครื่องที่เปิดใช้งานอยู่ ยอดจะไปโชว์ในบิลเครื่องนั้นตอนเช็คบิล แต่ยังคงแยกเป็น "รายการสินค้า" ในรายงาน
  2. **จ่ายแยก** — เลือกเงินสด / โอน / แลกแต้ม แล้วปิดการขายทันที (มี QR PromptPay ให้สแกนเมื่อเลือกโอน)
- ทุกการขายตัดสต็อกอัตโนมัติ และกันขายเกินสต็อก

## 3. บิลเครื่อง
- การ์ดเครื่องและหน้าเช็คบิล (PS5 และ PC) แสดงบรรทัด "🛒 สินค้า" พร้อมรายการย่อยและยอดรวม เพิ่มเข้ายอดที่ต้องชำระ
- ยกเลิกบิลเครื่อง → รายการสินค้าที่ผูกกับบิลนั้นถูกยกเลิกด้วย (คืนสต็อก) และไม่เข้ารายได้

## 4. บัญชีและสรุปยอด
- เพิ่มหมวด **"รายได้สินค้า"** แยกจากค่าเครื่อง/ค่าอาหาร ทั้งในสรุปตามช่วงวันที่และกราฟ 7 วัน
- ตารางสินค้าขายดี (ชื่อ, จำนวนที่ขาย, ยอดเงิน) ตามช่วงวันที่ที่เลือก
- พนักงานเห็นตารางรายการ/หมวดสินค้าได้ แต่ยังซ่อนการ์ดยอดรวมและกราฟตามเดิม

## รายละเอียดทางเทคนิค
- Migration ใหม่: `products` (barcode unique, name, price, stock, active), `product_sales` (เลขที่บิล, วันเวลาแบบเวลาไทย, ช่องทางจ่าย cash/transfer/points/on_machine, reservation_id, pc_session_id, status paid/cancelled, total), `product_sale_items` (product_id, ชื่อ+ราคาที่ขายจริง, qty, subtotal) พร้อม GRANT ให้ anon/authenticated + RLS แบบเปิดเหมือนตารางอื่นในระบบ และเพิ่มเข้า realtime publication
- ตัดสต็อก/คืนสต็อกผ่านฟังก์ชัน SQL แบบ atomic เพื่อกันสต็อกติดลบเมื่อขายพร้อมกันสองเครื่อง
- โค้ดใหม่: `src/lib/products.ts` (CRUD + checkout + รายงาน), `src/components/shop/ProductsPanel.tsx`, `ProductSalePanel.tsx`, `BarcodeScanner.tsx` (ใช้ BarcodeDetector ของเบราว์เซอร์ ถ้าไม่รองรับให้ fallback ใช้ไลบรารี zxing)
- แก้ไข: `src/routes/index.tsx` (แท็บใหม่ + STAFF_TABS), `ManageModal.tsx`, `MachineCard.tsx`, `PcZonePanel.tsx` (แสดง/รวมยอดสินค้า), `ReportPanel.tsx` (หมวดสินค้า), `reservations.ts`/`pcControl.ts` (ยกเลิกบิล → ยกเลิกรายการสินค้า)
- ไม่แตะโค้ด PC Agent (`pc-agent/`) เลย — ระบบล็อกหน้าจอไม่กระทบ
