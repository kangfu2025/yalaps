# แก้ปัญหาเกมเด้งออกขณะใช้งาน (PC Agent v2.5.0)

## สาเหตุที่พบจากการตรวจโค้ดจริง

1. **Overlay นับเวลาเป็นหน้าต่างโปร่งใส (layered) + Topmost ที่วาดใหม่ทุก 1 วินาที**
   `CountdownOverlay.xaml` ตั้ง `AllowsTransparency="True"` + `Topmost="True"` และ `Tick()` เขียน `TimeText.Text` ทุกวินาที ทำให้ DWM ต้อง composite หน้าต่างซ้อนบนเกมทุกวินาที เกมที่รันแบบ exclusive fullscreen (DirectX) จะถูกดีดออกจากโหมด fullscreen → หน้าจอกระพริบ/เกมย่อลง เป็นสาเหตุหลักที่ตรงกับอาการ "เด้งบ่อยมาก"

2. **`SizeToContent="WidthAndHeight"` + แถบเตือน (`WarnBox`) เปลี่ยน Visibility**
   ทุกครั้งที่แจ้งเตือน 10/5/1 นาที ขนาดหน้าต่างเปลี่ยน → บังคับ recomposite ซ้ำอีกครั้ง เพิ่มโอกาสดีดเกม

3. **`ShowLock()` ยังเรียก `Activate()` ได้ระหว่างมีเกมรัน**
   ถ้า `GetActiveSessionAsync()` คืน session ที่ถือว่าไม่ active ชั่วคราว (เน็ตกระตุก, เวลาเพิ่งหมดแล้วพนักงานเติมทีหลัง, เวลาเครื่องเพี้ยน) รอบ sync ทุก 30 วินาทีจะเปิดหน้าล็อกแบบ maximized + `Activate()` → แย่งโฟกัสจากเกมทันที และเมื่อ sync รอบต่อไปกลับมา active ก็ซ่อนอีก = อาการเด้งเป็นระยะ

4. **หน้าล็อกถูกซ่อน (Hide) ไม่ได้ปิด และยังคง `Topmost` จนถึงบรรทัดสุดท้าย** ลำดับ `Topmost=false` แล้ว `Hide()` ยังทำให้เกิด z-order change ระหว่างเกมทำงาน

## แผนแก้ไข

**A. เลิกใช้หน้าต่างโปร่งใสสำหรับ overlay**
- ตัด `AllowsTransparency` ออก ใช้ Border ทึบขนาดคงที่ (`Width`/`Height` fixed, ไม่มี `SizeToContent`) เพื่อไม่ให้เป็น layered window และไม่มีการเปลี่ยนขนาด
- อัปเดตข้อความเฉพาะเมื่อค่าที่แสดงเปลี่ยนจริง และเมื่อ overlay มองเห็นอยู่เท่านั้น

**B. โหมด "หลบเกม" (fullscreen detection)**
- ตรวจหน้าต่าง foreground ทุก 2 วินาที (`GetForegroundWindow` + เทียบขนาดกับ monitor และเช็ก `SHQueryUserNotificationState`) ถ้าพบแอปกำลัง fullscreen:
  - ซ่อน overlay ทั้งหมด (`Hide()`) ไม่ใช่แค่ปิด Topmost — ระหว่างเล่นเกมจะไม่มีหน้าต่างใด ๆ ซ้อนอยู่เลย
  - เมื่อออกจากเกม/สลับ Alt+Tab กลับมาเดสก์ท็อป จึงแสดง overlay กลับ
- แจ้งเตือนเวลาใกล้หมดระหว่างเล่นเกม: ใช้แถบ overlay ที่โผล่แค่ 8 วินาทีแบบไม่รับโฟกัส (ยอมให้ recomposite ครั้งเดียวต่อการเตือน แทนทุกวินาที)

**C. ห้ามแย่งโฟกัสโดยไม่จำเป็น**
- `ShowLock()` ตัด `Activate()` ทิ้งทุกกรณีที่หน้าล็อกแสดงอยู่แล้ว และหน่วงการล็อกจาก sync: ต้องอ่านค่า "ไม่มี session" ติดกัน 2 รอบ (≈60 วินาที) จึงจะเด้งหน้าล็อก ป้องกันเน็ตกระตุกทำให้เกมเด้ง
- เวลาหมดจริง (`OnTimeExpired`) ยังล็อกทันทีเหมือนเดิม — ไม่กระทบพฤติกรรมที่ต้องการ
- ปิด (Close) หน้าล็อกจริงเมื่อเข้าสู่ session แทนการ `Hide()` ค้างไว้ พร้อมสร้างใหม่เมื่อจำเป็น

**D. log เพิ่มเพื่อพิสูจน์ผล**
- log ทุกครั้งที่ overlay ซ่อน/แสดง เพราะ fullscreen detection และทุกครั้งที่หน้าล็อกถูก Activate เพื่อดูจาก `agent.log` ได้ว่าไม่มีการแย่งโฟกัสระหว่างเล่นเกมแล้ว

**E. ขยับเวอร์ชันเป็น 2.5.0 + build ให้พร้อมติดตั้ง**
- อัปเดต `AgentVersion` เป็น `2.5.0` เพื่อยืนยันบนหน้าแอดมินว่าเครื่องลูกใช้ build ใหม่
- build `win-x64` publish ให้เรียบร้อย แล้วติดตั้งทับด้วย `install.ps1` ตามเดิม (ไม่แตะการล็อกหน้าจอที่ใช้งานได้แล้ว)

## สิ่งที่ไม่แตะ

- ไม่แก้กลไกล็อกหน้าจอตอนบูต, registry, scheduled task, และการรับคำสั่งจากแอดมิน
- ไม่แก้สคีมาฐานข้อมูลและฝั่งเว็บแอดมิน

## วิธีทดสอบ

1. ติดตั้งทับ แล้วดูหน้าแอดมินต้องขึ้น Agent v2.5.0
2. เปิด session → เปิดเกม fullscreen ทิ้งไว้ 10-15 นาที ต้องไม่มีการเด้งออกเลย
3. Alt+Tab ออกมา ต้องเห็นแถบนับเวลากลับมาทันที
4. สั่งล็อก/ปิดเครื่องจากแอดมิน ต้องยังทำงานปกติ
5. เวลาหมด ต้องล็อกหน้าจอทันทีเหมือนเดิม
