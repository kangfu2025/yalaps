# เมนูควบคุมเครื่อง PC สำหรับ Admin

เพิ่มแผงควบคุมเครื่อง PC ที่ใช้ได้เฉพาะบัญชี Admin เพื่อสั่งล็อก/ปลดล็อก/ปิดเครื่องจากระยะไกล และกันไม่ให้พนักงานแอบใช้คอมพิวเตอร์

## สิ่งที่จะเพิ่ม

**แผงควบคุม PC (Admin เท่านั้น)** ในแท็บ "โซน PC" — การ์ดควบคุมของแต่ละเครื่อง มีปุ่ม:
- 🔒 ล็อกเครื่อง — สั่งล็อกหน้าจอทันที (ใช้ได้แม้ไม่มีลูกค้าเล่นอยู่)
- 🔓 ปลดล็อกชั่วคราว — สำหรับให้ Admin เข้าไปดูแลเครื่องเอง
- ⚡ ปิดเครื่อง — shutdown เครื่องลูก
- ⏻ ล็อกทุกเครื่อง / ปิดทุกเครื่อง — ปุ่มสั่งรวมทีเดียวทุกเครื่อง PC

ทุกปุ่มมีกล่องยืนยันก่อนสั่ง และปิดใช้งานเมื่อ Agent ออฟไลน์ พร้อมข้อความบอกสถานะ

**จำกัดสิทธิ์พนักงาน**
- พนักงานเห็นเฉพาะการ์ดสถานะ + เริ่ม/ปิด session ตามปกติ
- ปุ่ม ล็อก / ปลดล็อก / Shutdown ที่มีอยู่ตอนนี้จะถูกซ่อนจากพนักงาน (เหลือเฉพาะ Admin)
- เมื่อพนักงานปิด session ระบบยังสั่งล็อกเครื่องอัตโนมัติเหมือนเดิม

**บันทึกประวัติคำสั่ง (ตัวเลือกในหน้าเดียวกัน)**
แสดงรายการคำสั่งล่าสุดที่ส่งไปแต่ละเครื่อง (เวลา + ชนิดคำสั่ง) จากตาราง `pc_commands` ที่มีอยู่แล้ว เพื่อให้ตรวจสอบย้อนหลังได้ว่าใครสั่งอะไรเมื่อไร

## รายละเอียดทางเทคนิค

- `src/components/shop/PcZonePanel.tsx`: ใช้ `useAuth()` อ่าน `role`; ห่อปุ่มควบคุมด้วยเงื่อนไข `role === "admin"`; เพิ่มส่วน "ควบคุมเครื่อง (Admin)" ด้านล่างการ์ด พร้อมปุ่มสั่งรวม
- ใช้ `sendPcCommand(machineId, type)` เดิมใน `src/lib/pcControl.ts` (`lock` / `unlock` / `shutdown`) — ไม่ต้องแก้ Agent
- เพิ่ม `listRecentPcCommands()` ใน `src/lib/pcControl.ts` สำหรับดึง 20 คำสั่งล่าสุด และ subscribe realtime บน `pc_commands`
- ใช้ `ConfirmDialog` ที่มีอยู่แล้วสำหรับยืนยันทุกคำสั่ง
- ไม่แตะสคีมาฐานข้อมูล ยกเว้นถ้าต้องการเก็บว่า "ใครสั่ง" — จะเพิ่มคอลัมน์ `created_by uuid` ใน `pc_commands` (migration เล็ก ๆ พร้อม GRANT/RLS) เมื่อคุณยืนยันว่าต้องการ
